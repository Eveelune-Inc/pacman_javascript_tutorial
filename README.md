# Pac-Man JavaScript Tutorial 👻

A Pac-Man clone I built while learning **JavaScript** and **HTML Canvas**, following Code Fiction's *ASMR Programming - Coding Pacman - No Talking* tutorial.

This was one of my first substantial JavaScript projects and helped me become much more comfortable reading, writing, debugging, and understanding game code.

## 🎮 Features

- Pac-Man movement
- AZERTY-friendly controls
- Maze and food system
- Score tracking
- Ghosts with movement and pathfinding
- Ghost detection ranges
- Collision detection
- Lives and respawning
- Game Over state
- Win condition
- Sprite-based graphics
- Pixel-style UI using the Emulogic font

## ⌨️ Controls

| Action | Keys |
| --- | --- |
| Move Up | ↑ / Z |
| Move Down | ↓ / S |
| Move Left | ← / Q |
| Move Right | → / D |

## 🧠 What I Learned

While building this project, I practiced:

- JavaScript classes, objects and methods
- Functions and arrow functions
- Arrays and 2D arrays
- Loops and nested loops
- Conditions
- HTML Canvas
- Keyboard events
- Tile-based maps
- Collision detection
- Sprite sheets
- Basic enemy AI and pathfinding
- Distance calculations
- Game loops
- Win and loss conditions
- Debugging with browser DevTools

One of my biggest takeaways from this project was becoming more comfortable moving from simply **reading and recognizing code** to understanding patterns and predicting parts of the implementation myself.
